## Commands

### Test single image:
```bash
cd /home/ubuntu/research-agent-workflows
python comfyui/scripts/run_relight.py --input "https://example.com/image.png"
```

### Test with local file:
```bash
python comfyui/scripts/run_relight.py --input /path/to/image.png
```

### Test with custom prompt:
```bash
python comfyui/scripts/run_relight.py \
  --input "https://example.com/image.png" \
  --prompt "Relight with dramatic studio lighting..."
```

## Manual SSH Commands (for debugging)

### Check if ComfyUI is running:
```bash
ssh ubuntu@54.159.123.145 "curl -s localhost:4000/system_stats | head -c 100"
```

### List input folder:
```bash
ssh ubuntu@54.159.123.145 "ls -la /home/ubuntu/ComfyUI/input/"
```

### List output folder:
```bash
ssh ubuntu@54.159.123.145 "ls -la /home/ubuntu/ComfyUI/output/"
```

### Copy file to GPU:
```bash
scp /local/path/image.png ubuntu@54.159.123.145:/home/ubuntu/ComfyUI/input/
```

### Copy file from GPU:
```bash
scp ubuntu@54.159.123.145:/home/ubuntu/ComfyUI/output/result.png /local/path/
```

### Queue a prompt manually:
```bash
ssh ubuntu@54.159.123.145 'curl -X POST http://localhost:4000/prompt \
  -H "Content-Type: application/json" \
  -d @- << EOF
{"prompt": <workflow_json>}
EOF'
```

### Restart ComfyUI (if crashed):
```bash
ssh ubuntu@54.159.123.145 "cd /home/ubuntu/ComfyUI && source venv/bin/activate && pkill -f 'python main.py' ; nohup python main.py --port 4000 > /tmp/comfyui.log 2>&1 &"
```

### Check ComfyUI logs:
```bash
ssh ubuntu@54.159.123.145 "tail -50 /tmp/comfyui.log"
```

## Workflow JSON Key Nodes

- Node "19": LoadImage - set `inputs.image` to input filename
- Node "17": CLIP Text Encode (Positive Prompt) - set `inputs.text` for prompt
- Node "13": Image Save - set `inputs.filename_prefix` and `inputs.output_path`

## Troubleshooting

### ComfyUI not responding:
1. SSH to GPU: `ssh ubuntu@54.159.123.145`
2. Check tmux: `tmux a -t run`
3. Restart if needed: `python main.py --port 4000`

### Workflow fails:
1. Check GPU has required models
2. Check ComfyUI logs for errors
3. Verify input image was copied correctly

### Azure upload fails:
1. Check .env has credentials
2. Verify AZURE_STORAGE_CONNECTION_STRING
3. Test upload script directly
